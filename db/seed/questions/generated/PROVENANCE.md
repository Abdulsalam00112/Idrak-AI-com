# Content provenance — generated/ batch

## What's in this folder (updated: expanded batch)

763 practice questions across 8 exams — JAMB 100, WAEC 100, NECO 100, Post-UTME 100,
SAT 100, ICAN 100, CITN 100, IELTS 63. All written from scratch for this project;
none is past-paper content.

**IELTS is 63, not 100** — deliberately. Its content splits across Reading, Listening,
Writing, and Speaking, and the last two don't decompose into large volumes of
non-duplicate multiple-choice questions the way factual/quantitative subjects do
without either padding with near-duplicates or drifting into low-quality filler.
63 distinct, checked questions across all four skills; not stretched to 100 by
compromising on that.

Quantitative subjects (Mathematics, SAT Math, ICAN/CITN Financial Accounting) are
generated by small Python scripts (`_gen/math_gen.py`, `_gen/accounting_numeric.py`)
that compute the correct answer directly — e.g. simple interest, simultaneous
equations, depreciation, VAT — so correctness comes from arithmetic, not typing.
Conceptual subjects (Physics, Biology, Chemistry, Economics, Government, Business
Law, Taxation, English vocabulary/idioms, IELTS content) are built from curated
fact banks in `_gen/bank_*.py`, turned into MCQs by `_gen/facts_engine.py`, which
draws wrong-answer options from *other* facts in the same bank rather than
inventing distractors.

Every file was validated through the actual importer (`import.ts --dry-run`):
100% pass rate, and a separate check confirmed zero duplicate question text and
a single, correct exam code within each file.

## Why there's no real past-paper content here

Before writing this batch, I researched whether legitimately licensed real
question content was available for any of the 8 exams:

- **JAMB / WAEC / NECO / Post-UTME**: several Nigerian "past questions API"
  projects exist on GitHub (e.g. ALOC, SdashAPI) that license their *code* as
  MIT. That's not the same as the underlying *question content* being licensed
  for reuse — the questions themselves originate from JAMB/WAEC/NECO, which are
  the copyright holders, and an MIT license on a wrapper API doesn't establish
  that those boards authorized redistribution. I found no evidence of such
  authorization, so I did not treat this content as usable.
- **SAT**: College Board's own SAT Suite Program Agreement explicitly prohibits
  "copying, disseminating, publishing, displaying or distributing in any form...
  any questions from the assessments... without the prior written consent of
  College Board." Definitively closed.
- **IELTS**: jointly owned by the British Council, IDP, and Cambridge University
  Press & Assessment; official practice materials are sold commercially with
  reproduction restricted to specific licensing schemes or written consent.
  Definitively closed.
- **ICAN**: the Institute does appear to make its own Pathfinder past
  questions/answers freely downloadable from its own site for candidates.
  This is more open than the others, but "free to download for personal study"
  is not the same as an explicit license to import and redistribute inside a
  third-party commercial product — no such license was found, and the content
  remains "properties of ICAN" per the sources that host it.
- **CITN**: similar publisher/institute-compiled past-question packs exist, with
  no explicit redistribution license found.

Given none of the 8 exams had a dataset meeting the "properly licensed /
explicitly permits the intended use" bar, the only legitimate content I could
add myself was original, clearly-labeled generated practice questions — which
is what this folder contains. Nothing here should ever be presented to a user
as an official past question.
